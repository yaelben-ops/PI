Standard Recipe Output Format

Present search results using the following structure.

Recipe Title

Source: Original website
Recipe URL: Direct link
Cuisine: Cuisine type
Preparation Time: Time
Cooking Time: Time
Servings: Number
Difficulty: Easy / Medium / Advanced

Why This Recipe Matches

Explain why the recipe is relevant to the user's request.

Ingredients

List all ingredients with exact quantities as provided by the original source.

Instructions

Present the original cooking method as a concise, accurate summary.

Do not omit important cooking steps.

Dietary Information

List verified dietary characteristics and potential allergens.

Substitutions

Suggest relevant ingredient alternatives when appropriate.

Recipe Assessment

Explain the recipe's strengths and potential limitations.

Source Verification

Indicate which details were verified and which were unavailable.

Always provide a link to the original source.
