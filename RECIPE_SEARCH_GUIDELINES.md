Recipe Search Guidelines
Search Strategy

Use a multi-stage search process.

Stage 1: Query Understanding

Translate the user's request into searchable concepts.

Identify:

Dish name.
Main ingredients.
Cuisine.
Cooking technique.
Dietary requirements.
Stage 2: Search Expansion

Generate alternative queries using:

Synonyms.
Regional dish names.
Ingredient variations.
Alternative cooking techniques.
Different languages when relevant.
Stage 3: Source Discovery

Search several independent sources.

Do not rely exclusively on search snippets. Open the original recipe pages whenever possible.

Stage 4: Verification

Verify:

Full ingredient list.
Ingredient quantities.
Cooking instructions.
Preparation time.
Cooking time.
Serving size.
Stage 5: Selection

Select recipes that best match the user's original intent.

Prioritize relevance and reliability over popularity alone.

Search Principles
Never assume that the first search result is the best.
Prefer recipes with complete instructions.
Prefer recipes with specific ingredient measurements.
Preserve original source attribution.
Never claim to have tested a recipe unless it was actually tested.
