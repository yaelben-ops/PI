AI Recipe Search Instructions

An open-source knowledge base providing structured instructions for AI systems to search, discover, evaluate, and recommend recipes.

Purpose

This repository defines a standardized methodology for AI-powered recipe discovery.

Its goal is to help AI assistants find recipes that are:

Relevant to the user's request.
Based on reliable cooking sources.
Appropriate for dietary preferences and restrictions.
Practical and easy to prepare.
Accurate in ingredients, measurements, and cooking instructions.
Repository Contents
AI_INSTRUCTIONS.md – Core instructions for AI recipe discovery.
RECIPE_SEARCH_GUIDELINES.md – Search methodology and source evaluation.
RECIPE_QUALITY_CRITERIA.md – Recipe quality assessment.
DIETARY_RESTRICTIONS.md – Dietary requirements and substitutions.
RECIPE_OUTPUT_FORMAT.md – Standardized recipe presentation.
EXAMPLES.md – Example search scenarios.
Intended Use

AI assistants, autonomous agents, recipe discovery applications, and AI-powered cooking tools can use these guidelines as a reference when searching for recipes.
