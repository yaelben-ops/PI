Recipe Quality Criteria

Evaluate each recipe using the following criteria.

Criterion	Description
Relevance	Matches the user's request
Completeness	Contains all ingredients and instructions
Clarity	Instructions are understandable
Reliability	Source is credible
Practicality	Ingredients are accessible
Time	Preparation time is reasonable
Adaptability	Offers useful substitutions
Feedback	Includes user reviews when available
Quality Rules

A recipe should not be recommended as a complete recipe if essential ingredients or cooking instructions are missing.

If information is unavailable, explicitly mark it as unavailable.

Never invent ratings or user reviews.
